# Kenganal Calculator

A responsive calculator website recreated from the supplied Thunkable calculator design using plain HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Decimal numbers, percentage, clear, and backspace
- Live result preview and equals action
- Light and dark themes
- Keyboard support
- Responsive layout for phones and desktop browsers

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy with GitHub Pages
1. Create a GitHub repository named `everyday-calculator`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your URL will look like:
   `https://YOUR-USERNAME.github.io/everyday-calculator/`

This project is a static website and does not require a backend server.
